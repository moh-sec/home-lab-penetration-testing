# Connectivity Verification

## Purpose
Verify that all lab machines can communicate with each other before starting any penetration testing activities.

---

## Steps Performed
1. Ping from Windows to Kali Linux
2. Ping from Kali Linux to Windows
3. Identify and resolve any ICMP firewall restrictions

---

## Outcome
Bidirectional connectivity was successfully established between all lab machines.
